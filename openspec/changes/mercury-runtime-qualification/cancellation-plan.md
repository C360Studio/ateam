## Plan and acceptance checks

1. **Freeze ownership and controls.** Reconcile the installed CLI, dependency/source hashes and isolated environment before any execution. Reuse verified existing dependencies without upgrades. Each attempt owns a fresh CLI home, bridge, process groups, output directory and loopback fixture, with fake credentials and OS-denied external egress. Keep native writes to evidence denied and the effective zero-retry controls measured. Record process identity and start identity when ownership is established; never signal a reused/unrelated PID or group based only on a saved integer or stale identity check. Establish trustworthy group ownership before signalling and refuse ambiguous ownership.
2. **Separate native propagation from supervisor teardown.** Preserve an unassisted cancellation observation as a distinct control. A supervisor may deliberately stop the per-attempt bridge when the CLI ends or capture fails; label that outcome supervised transport teardown, not native cancellation propagation. No bridge/SDK fork or private monkeypatch is assumed. If the native path or supported ownership controls cannot meet the contract, report the blocker rather than weaken it.
3. **Observe the boundary independently.** Synchronize on fixture request receipt and durable first capture chunk before midstream cancellation. The fixture must observe actual socket closure without first manufacturing a disconnect; record monotonic event order, cancellation/exit, TERM/KILL, socket-close and cleanup observations. The final fixture disposal is separate and cannot count as successful cancellation. Freeze bounded readiness, whole-attempt and teardown deadlines before running; report elapsed time and which deadline failed. Use no guessed sleep to establish ordering.
4. **Clean up after leader exit and failure.** Inspect the owned group even when its direct leader already exited. Use bounded TERM→KILL escalation and wait/reap direct children; independently observe owned-group/known-descendant absence before accepting cleanup. Distinguish absent, zombie, live, inaccessible and identity-mismatched observations. Include a same-group child surviving its leader and a child ignoring TERM. An escaped or unobservable descendant must be an explicit limitation/refusal, not proof of absence; do not broaden permissions or kill unrelated processes to make the test pass.
5. **Retain failure accounting.** Exercise cancellation before first response data and during a partial stream, native error/early exit, bridge failure, capture-write failure, and a supervisor exception through its normal cleanup path. Compare the fixture's request ledger with capture intents/IDs and assert no retry/fallback or follow-on request within each bounded history. Cancellation/failure stays incomplete/unknown even when shutdown succeeds or a local file looks like EOF; teardown does not retroactively make usage complete. Include a completed response as the positive control.
6. **Prove the tests discriminate.** Use a test-owned lifecycle model for deterministic histories (including leader-before-child exit), explicit activation counts and real owned child processes for signal behavior. Establish meaningful failing regressions before fixes. Non-destructive copied-source mutations should detect skipping cleanup after leader exit, ignoring a surviving child, counting fixture-forced disconnect as cancellation, accepting partial usage as complete, or retrying after failure. Record baseline/after passes, exact detection/survivor/invalid/inconclusive verdicts and unchanged original hashes. No test may signal arbitrary system processes.
7. **Deliver reviewable evidence.** Publish redacted event timelines, independent fixture/process observations, source pins, bounded results and replay commands. Keep raw native prompts/private paths local. Run explicit research checks, clean-tree `task verify`, doctor and strict OpenSpec, then independent technical review and owner-arranged cross-service review before merge. Do not infer real provider computation cancellation or billing from a local socket close.
