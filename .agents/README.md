# Agent & Platform Configuration (`.agents/`)

`.agents/` holds the single set of instructions, workflow rules, and skills shared across **Claude Code**, **Codex CLI**, and **Gemini CLI**. The files under `.claude/`, `.codex/`, and `.gemini/` are thin pointers generated by `ateam init` and checked by `ateam doctor`.

## Adoption scope

ATeam is an opinionated experimentation lab primarily grounded in Go development. Initialization uses the same templates for all project languages; it does not detect language support or create a Taskfile. Review and adapt these instructions before adoption. Go mutation checks require non-test .go source; verification targets belong to the adopting project. Shortcut scanning covers only .go, .ts, .js, .svelte, .sh, .yml, and .yaml files (excluding Go tests and .test.ts files). Other languages are not validated as complete workflows. Ponytail modes change injected guidance, not model settings or guaranteed compliance. Benchmark self-tests validate reference fixtures, not improved agent performance.

See [the adoption guide](../docs/adoption.md) for command dependencies, scanner limits, and verification setup. The Go/Svelte gates below describe this repository; adopting projects must define suitable equivalents.

Read [how the harness runs](../docs/hook-flow.md) for event effects, injected context, design opinions, and failure behavior.

## Shared Skills

Canonical skills live in `.agents/skills/<name>/SKILL.md`:

- [pickup](skills/pickup/SKILL.md): check live git branch, `HEAD` SHA, worktrees, GitHub/Gitea issues and PRs, open `Hold:` items, and any commits since the last handoff.
- [handoff](skills/handoff/SKILL.md): save a 5-field checkpoint (`Goal`, `Addresses`, `Constraints`, `Done when`, `Checks to run`), release the session writer lease, and print the pickup block for the next session.
- [preflight](skills/preflight/SKILL.md): run the matching `Taskfile.yml` verification checks and record test/mutation output before pushing or finishing.
- [ponytail](skills/ponytail/SKILL.md): write the smallest complete change that solves the task, track intentional limits with `// shortcut: <limit>, <when to upgrade>`, and end replies with 1–2 lines naming what was skipped and any remaining risk.

## What `ateam doctor` Checks

1. `AGENTS.md`, `CLAUDE.md`, `.agents/README.md`, `.agents/protocol.md`, `.agents/rules-index.md`, and `openspec/config.yaml` exist and are non-empty.
2. `CLAUDE.md` imports `@AGENTS.md`, stays within 10 lines, and does not define its own section headings or rule tables.
3. `AGENTS.md` stays strictly under 24,000 bytes and matches `.agents/rules-index.md` in numbered rule sections and row counts.
4. Every canonical skill in `.agents/skills/<name>/SKILL.md` has a matching thin pointer in `.claude/skills/<name>/SKILL.md` and `.gemini/commands/<name>.toml`.
5. `.claude/settings.json`, `.codex/hooks.json`, and `.gemini/settings.json` wire all four lifecycle events (`session-start`, `before-prompt`, `pre-compact`, `turn-end`) with `--agent claude|codex|gemini` and register the `ateam mcp` server, and `.agents/hooks.json` plus `.agents/plugins/ateam/` wire `session-start`, `before-prompt`, `turn-end` (`--agent agy`) and `ateam mcp` for Antigravity.
